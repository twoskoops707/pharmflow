    Step 4 of 9

    Phones

    Step 4 of 9 — connect phones and let CPharm set them up.

    What to do

    1. Start each phone in MuMu.
    2. Turn on USB debugging (Settings → Developer options). Leave it on — CPharm needs it; websites still get disguised during setup.
    3. If MuMu shows Root, leave it ON.
    4. Click Check again, then Set up my phones.
    5. CPharm installs Chromium, disguises each phone, and finishes setup.
    6. If asked, restart phones and run setup again.
