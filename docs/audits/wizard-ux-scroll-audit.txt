CPharm Wizard — UX scroll audit (2026-06-21)
============================================
File: wizard/setup_wizard.py (+ wizard shell in CPharmWizard)

ROOT CAUSE
----------
Tk ``Canvas.create_window`` embeds each page. Child frames packed with
``fill="both", expand=True`` grow to the *viewport* height, not content height.
``scrollregion`` stays viewport-sized → bottom controls/options clip with no
way to scroll to them. Fix: use ``fill="x"`` for vertical stacks inside
canvas-embedded pages; use dedicated Canvas+Scrollbar for dialogs; keep OK/Cancel
in a fixed footer outside the scroll region.

PATTERN (matches existing code)
-------------------------------
- Canvas + themed_vertical_scrollbar + inner Frame + create_window
- canvas_set_scrollregion_from_bbox_all on <Configure>
- canvas_embed_set_width on canvas <Configure>
- _bind_nested_canvas_mousewheel for Windows/Linux wheel
- Bottom padding Frame (height ~16–32) so last row is not flush against edge
- CPharmWizard._on_mousewheel: scroll nested canvas under pointer when present
