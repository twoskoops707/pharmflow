## Humanization

- Each combo uses a stable seeded RNG (`home-combo-snowflake-v1`).
- Micro-waits, tap jitter, and swipe ms vary per file; timer long-waits stay exact.

## Action dictionary

- `open_url`: Launch URL using Android VIEW intent fallback chain.
- `tap`: Scaled coordinate tap (`base_w`/`base_h`) with retry+jitter.
- `swipe`: Scaled coordinate drag for viewport navigation.
- `wait`: Explicit timing gate for UI/network stabilization.
- `keyevent`: Android hardware key (`4` BACK, `66` ENTER).
- `type_text`: Send text to focused input.
- `clear_cookies`: Browser session cleanup (`pm clear` + force-stop fallback).
- `close_app`: Force-stop target app package.
- `rotate_identity`: Tor circuit/proxy rotate (IP change).
- `full_reset`: Full identity reset (IP + Android ID + cleanup).

## Rationale by sequence block

- Entry block: controls landing source realism (`direct` vs `google_home`).
- Home choice block: parameterizes footer/hero/bottom touch-path choices.
- Timer lead-in block: normalizes scroll/context before timer decisions.
- Timer block: isolates long-wait behavior into reusable policy options.
- Identity tail block: enforces explicit IP+ID change at sequence end.
